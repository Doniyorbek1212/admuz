Инструкция

Короткое руководство по установке UZARO и основным возможностям.

Установка

Удобнее всего установить «UZARO Messenjer» из Google Play. Если на телефоне нет Google Play, установите APK:

Скачать в Google PlayОбновляется автоматически

  1. Нажмите «Скачать для Android» на этом сайте.
  2. Откройте скачанный файл UZARO.apk.
  3. Если телефон попросит разрешить установку из неизвестных источников, дайте это разрешение браузеру.
  4. Когда установка закончится, откройте UZARO.

Скачивайте файл только с uzaromessenger.uz. Копии из других каналов и сайтов могут быть изменены.

Установка на Windows

  1. Нажмите кнопку «Windows» и скачайте файл UZARO-Setup.
  2. Запустите файл. Права администратора не нужны: приложение устанавливается только для вашего пользователя.
  3. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» и «Выполнить в любом случае». Окно появляется, потому что приложение пока не подписано цифровой подписью.
  4. Откройте UZARO и войдите по номеру телефона или по QR-коду через Telegram на телефоне.

Вход

  1. Введите номер в международном формате: +998 …
  2. Введите код, пришедший в Telegram или по SMS.
  3. Если включена двухэтапная проверка, введите и пароль.
  4. Позже можно добавить ещё 11 номеров и переключаться между ними одним нажатием.

Режим «Призрак»

  • Откройте боковое меню и включите «Ghost режим».
  • Пока он включён, собеседники не получают «прочитано», «печатает…» и статус «в сети».
  • Режим действует во всех чатах, пока вы его не выключите.

Удалённые сообщения

  • Оригиналы удалённых или изменённых собеседником сообщений попадают в архив.
  • Архив хранится только на этом телефоне и никуда не отправляется.
  • Сообщение остаётся в архиве, только если приложение успело получить его до удаления.

PIN-код

  • Включите PIN-код в настройках и задайте 6 цифр.
  • Выберите время автоблокировки: каждый раз или через несколько минут.
  • После 5 неверных попыток время ожидания до следующей попытки растёт.

Если забыли код, переустановите приложение и войдите по номеру Telegram. Чаты хранятся в Telegram, но архив удалённых сообщений на телефоне пропадёт.

Открыть магазин

  1. Нажмите Подборка → Бизнес-профиль → «Открыть магазин».
  2. Укажите название, описание, регион и телефон или username в Telegram для связи.
  3. Нажмите «Сохранить и отправить на проверку». После одобрения администратором магазин увидят покупатели вашего региона.
  4. Добавьте товары: название, цену, фото и отметку «В продаже».

Первые 2 магазина бесплатны. После каждого изменения магазин проверяется заново.

Разместить рекламу

  1. Нажмите Бизнес-профиль → «Разместите свою рекламу».
  2. Введите заголовок, короткий текст и ссылку на фото или видео.
  3. Выберите регионы и срок, итоговая цена посчитается сразу.
  4. Переведите деньги на указанную карту и загрузите фото чека.
  5. После проверки чека администратором реклама появится в баннере.
